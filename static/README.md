# Tresor V2 static prototype

Open `index.html` directly in a browser. No build step or dependency install is required.

The prototype mirrors the Figma v2 customer journey:
Home → Menu → semantic-style search → Product → Cart → Checkout → mock payment → Order Confirmation → Tracking, plus About, Contact and Account.

The cart persists in `localStorage`. Checkout creates a mock order id. Zomato/Swiggy links are placeholders.
